Wardrobe Manager – ER Diagram

12 tables · 14 relationships · MySQL schema

Hierarchical categoriesCategories references itself via parent_category_id: Clothing → Colour / Season / Type / Fabric → Blue, Winter, Jeans, Cotton.
Junction tablesItemCategories, OutfitItems and OutfitOccasions turn many-to-many links into two one-to-many links.
Plan, wear, rateOutfitPlans schedules an outfit; WearLogs records each wear with four optional 1–5 ratings.
Top-3 suggestionsSuggestedOutfits links each ranked pick (top 3 per request) to an outfit and a wear log, with the score at that moment.
